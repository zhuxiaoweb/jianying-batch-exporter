# jianying-batch-exporter

剪映交付助手是一个 Windows 10 x64 桌面工具，用于批量导出剪映专业版本地草稿。它读取草稿库和时间线，支持按剧名、集号搜索和多选，并将选中的时间线整理成四版 MP4 和可用的 SRT 字幕。

当前预览版为 `2.3.22-preview1`。作者为 **zhuxiao**，邮箱为 [zhuxiaoweb@163.com](mailto:zhuxiaoweb@163.com)。

## 从源码运行

1. 在 Windows 10 x64 上安装带 Tcl/Tk 的 Python 3.12 x64，以及剪映专业版。开发和验收使用剪映 `11.7.0.14652`，程序从其安装目录调用 `ffmpeg.exe` 和 `ffprobe.exe`。
2. 克隆本仓库，在仓库根目录打开 PowerShell，执行以下命令。

   ```powershell
   py -3.12 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe main.py
   ```

3. 首次打开时，助手会准备独立的剪映 `11.6.0.14552` 后台引擎并进行合成素材自测。首次下载和解压约需要 4.3 GiB 可用空间，草稿备份与交付成片另计。离线准备和本地 EXE 构建见 [开发说明](docs/development.md)。
4. 在剪映保存草稿后回到助手，刷新并勾选时间线，选择交付位置，点击「开始制作交付包」，再逐集确认长配乐和字幕。未找到草稿时，可在界面中指定本地草稿库或单个草稿目录。

## 输出文件

视频规格为 **1080 × 1920、60 fps、9:16、MP4**。新批次默认按列表显示的剧名和视频版本归档。例如，一条名为「时间线01」的时间线会生成以下文件。

```text
导出批次_…/
└── 交付/
    └── 剧名/
        ├── V1_无背景音乐_无字幕/时间线01.mp4
        ├── V2_无背景音乐_有字幕/时间线01.mp4
        ├── V3_有背景音乐_无字幕/时间线01.mp4
        ├── V4_有背景音乐_有字幕/时间线01.mp4
        └── 字幕srt/时间线01.srt
```

- 无配乐版移除用户明确勾选的独立长配乐，保留人声、环境音、音效和短音乐。烧录在素材画面里的字幕及已混入素材音轨的音乐会随原素材保留。
- 缺少可导出字幕或独立音轨时，界面会提示确认。无可导出字幕的时间线可继续交付四版，SRT 项记为缺项。
- 同名剧归到同一个剧名目录。时间线文件重名时加任务短编号。批次开始时冻结输出路径，每个草稿先完整备份。停止后可从「任务清单.json」继续制作。
- 助手完成两次后台渲染，再组合音视频流生成另两版。归档前校验媒体包时序、音频和四版完整解码。界面会标记待声画审核。

## 兼容范围

后台引擎固定使用 `11.6.0.14552`，与日常剪映安装独立。此版新增对 `193.0.0` 根草稿及活跃子草稿的兼容。导出还要求所用素材可访问，并通过模型字段、音频处理和效果检查。已验收范围包括开发机和使用合成素材的 Windows 预览包，不同电脑上的真实草稿与人工声画审核仍需按实际项目验证。

真实启动时，助手默认关闭剪映自动更新，并关闭「参与内测体验计划」。可在设置中修改自动更新偏好。写入限于剪映配置中的 `enableAutoUpdate` 和 `joinBeta`，已有配置会先备份。剪映顶栏的新版提示仍由剪映管理。

## 源码与许可

- `main.py`、`jyexport/` 提供界面、扫描、任务调度与交付验证。
- `native/` 保存 Windows 后台辅助程序源码。
- `tools/headless-engine/` 提供引擎准备脚本、辅助程序与哈希清单。
- `tests/` 保存回归测试。测试与构建步骤见 [开发说明](docs/development.md)。
